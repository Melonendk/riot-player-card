## What is the project?

So this is a player card maker for Riot id's and a checkin tool to help organizers / players to scan official riot id qr codes from the app or from these generate text QR-codes.

## Getting Started

Its requires **NodeJS** & **pnpm**. Then all you have to do is clone the repo, install packages with `pnpm i`. Then run `pnpm run dev`.
